# MathMate - Your Smart Maths Companion

A multi-functional mathematical learning platform built using R Shiny.

### Outcome
App run agi [1] 15 output kuduthu - 10+5=15

### 8 Modules
1. Calculator - Addition & Metrics
2. Vector Lab
3. Matrix Lab
4. Statistics Lab - Mean, Median
5. Student Table
6. Graph Studio - Plots + Geometric
7. Quiz - Learning Check + Score
8. About

### Block Diagram Flow
USER INPUTS -> CALCULATOR -> VECTOR & MATRIX -> STATS & TABLE -> GRAPH STUDIO -> QUIZ -> RESULT [1] 15
